# 鋼琴節拍器：安裝到 iPad／iPhone

這個資料夾裡的檔案就是完整的 App。放到一個 HTTPS 網址，再用 Safari「加入主畫面」，之後就能離線使用。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 節拍器本體（介面、音訊引擎都在裡面） |
| `manifest.json` | 讓它加入主畫面後像 App 一樣全螢幕開啟 |
| `sw.js` | 離線快取 |
| `icons/` | App 圖示 |

## 用 GitHub Pages 放上網（只用網頁操作，免費）

1. 到 github.com 註冊並登入。
2. 右上角「+」→「New repository」。名稱例如 `metronome`，選 **Public**，按「Create repository」。
3. 在新頁面點「uploading an existing file」，把這個資料夾裡的 **所有檔案和 icons 資料夾** 拖進去，按「Commit changes」。
4. 進入 repository 的「Settings」→ 左側「Pages」。
   「Branch」選 `main`、資料夾選 `/ (root)`，按「Save」。
5. 等 1–2 分鐘，頁面上方會出現網址，例如 `https://你的帳號.github.io/metronome/`。

## 加入主畫面

1. 在 iPad／iPhone 用 **Safari** 開啟上面的網址（要有網路）。
2. 點「分享」按鈕 →「加入主畫面」。
3. 從主畫面的「節拍器」圖示開啟一次，讓它把檔案存好。
4. 之後開飛航模式測試：從主畫面開啟應該仍可正常使用。

## 之後更新版本

把新的檔案重新上傳到同一個 repository（覆蓋舊檔）。
App 在有網路時開啟，會在背景抓新版，**再開一次**就會看到更新。

## 曲目與練習

- **曲目**分頁：新增曲目會用目前的拍號、重音和細分拍存起來。點曲目就會載入它的「目前速度」。練到更快之後，按節拍器下方的「記下 ♩=…」更新目前速度。
- **練習**分頁：
  - 漸進加速：每隔幾小節自動加快，直到目標速度。選了曲目時，目標就是那首曲子的目標速度。
  - 靜音小節：例如響 3 小節、停 1 小節，停的時候畫面也不閃，靠自己數拍。
  - 練習紀錄：每次練 10 秒以上會自動記錄，顯示今天和最近 7 天的練習時間。
- **備份**：資料只存在這台裝置上。建議偶爾在「練習 → 匯出備份檔」存一份到「檔案」App 或 iCloud Drive；換裝置或資料不見時，用「從備份檔匯入」還原。

## 使用小提示

- 介面有中文和 English，預設跟著裝置語言，可在設定最下方的「語言 Language」切換。
- 第一次按「開始」才會有聲音，這是 iOS 的規定。
- 靜音鍵開著也會響（iOS 17 以上最穩定）。
- 播放時螢幕不會自動關閉。切到其他 App 或鎖屏時聲音會停，這是網頁 App 的限制。
- 點一下拍子方塊可以切換「重音 → 普通 → 靜音」。
- 點一下大大的速度數字可以直接輸入。
- 藍牙翻譜踏板：空白鍵、Page Up／Page Down 都是開始／停止；方向鍵 ↑↓ 調 ±1，←→ 調 ±5。
